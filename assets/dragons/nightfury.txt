== Trivia ==
* Using a name tag to name any Night Fury "Toothless" will give it a new skin that resembles Toothless from the original How To Train Your Dragon trilogy
* A Night Fury and a [[Light fury|Light Fury]] can be bred to make a [[Night Light]]
*
*
* There is a rare albino variant of the Night Fury with a 1/1000 spawnrate
* In order to use a Night Fury's special ability, you must charge up a plasma blast to the highest level by holding the special ability key.

== Summoning Specific Variants ==
If you want a specific variant of the nightfury and you are playing on the 1.18.2 version, the command below should allow you to get them. (You replace the # with the Variant Number.)

/summon isleofberk:night_fury ~ ~ ~ {variant:#}

If the above command doesn't work, use this command:

/summon isleofberk:night_fury ~ ~ ~ {VariantName: ""}

(insert the variant name in all lowercase between the quotation marks, use an underscore in place of spaces)

Variant numbers listed in Image Gallery.
